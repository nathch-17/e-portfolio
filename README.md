# E-Portfolio — Nathan Chaignon (`@nathch-17`)

Site **E-Portfolio** généré à partir du thème **E-Portfolio** (*Folio Kit – Portfolio & Case Study UI Kit* + *Minimalist Figma Portfolio Template Responsive*), mettant en avant les projets GitHub de **Nathan Chaignon** (`https://github.com/nathch-17`).

## Projets mis en avant (Études de Cas Folio Kit)

1. **Viking Transport (`site_viking_transport`)** — Site web complet en PHP & MySQL réalisé en groupe en 3 jours (BUT Informatique) pour une entreprise fictive de transports en commun en Normandie (réservation, horaires, carte, espace client et back-office administrateur).
2. **Raycaster 3D Engine (`raycaster-raylib-c`)** — Moteur graphique de type Raycaster en C avec Raylib (algorithme DDA, gestion des collisions, textures et HUD).
3. **YINSH Java & JavaFX (`YINSH_java` & `YINSH_UI`)** — Jeu de stratégie abstrait sur plateau hexagonal développé en Java 21 & Maven (sprint de 2 jours en équipe de 4 pour le moteur + interface graphique JavaFX).
4. **Dotfiles Hyprland & Wayland (`dotfiles2`)** — Configuration Linux complète : Hyprland, Quickshell, DankMaterialShell, WezTerm (Lua), Neovim, Fish, Rofi, Yazi, Lazygit et thèmes GTK / Firefox CSS.
5. **My Malloc — Memory Allocator (`memory-allocator`)** — Réimplémentation de `malloc` en C : gestion du tas (heap), alignement mémoire, découpage de blocs (splitting) et tests unitaires.

Ainsi qu'une section dédiée aux autres dépôts GitHub (`MemeDrop`, `Gribouille_projetBUT`, `SAE101`, `memory`).

## Démarrage rapide

### Option 1 : Aperçu immédiat sans installation (`preview.html`)
Ouvrez directement le fichier [`preview.html`](./preview.html) dans votre navigateur pour tester l'intégralité du portfolio et des études de cas interactives immédiatement.

### Option 2 : Environnement de développement Vite + React + Tailwind CSS
```bash
npm install
npm run dev
```

Pour compiler la version de production :
```bash
npm run build
```
